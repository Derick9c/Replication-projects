# Replication Projects

This repository contains my replication work of academic papers in computational social science, econometrics, and related quantitative fields.

---

## Purpose
This repository is used to reproduce existing research papers to better understand their methods, identification strategies, and empirical implementations.

---

## Structure
Each project corresponds to one replicated paper and includes:

- original paper reference  
- data (or data construction process)  
- code implementation  
- figures and tables  
- reproduced results
